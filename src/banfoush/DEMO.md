# بنفوش — دليل العرض النهائي

بنفوش هو الوحش البنفسجي في الشاشة الرئيسية، وصار مساعداً ذكياً:
عيناه تلاحقان الماوس، يراقب تصرفات الطالب ويتكلم من نفسه، ويرد على
الأسئلة. عنده **دماغ محفوظ** (ردود فورية وثابتة لا تخطئ، تعمل بدون
إنترنت)، وما لا يعرفه يسأل عنه **Grok** (ذكاء اصطناعي) ويكتب الجواب حرفاً حرفاً.

## قبل العرض

1. شغّل المشروع: `npm run dev` ثم افتح `http://localhost:5173` (يفضل **Edge** لأن صوته العربي أجمل).
2. الذكاء الاصطناعي يعمل فقط مع `npm run dev` أو `npm run preview`، والمفتاح محفوظ في `.env.local` (لا يُرفع لـ GitHub).
3. اضغط **Alt+Shift+R** لمسح ذاكرة بنفوش، حتى يبدأ العرض بالترحيب من الأول.
4. (اختياري) افتح المحادثة واضغط زر السماعة 🔊 في رأس النافذة ليحكي بنفوش بصوت.

## سيناريو العرض المقترح (بالترتيب)

| # | ماذا تفعل | ماذا يفعل بنفوش |
|---|-----------|-----------------|
| ١ | افتح الصفحة واترك الماوس يتحرك | بعد ثانيتين: «أهلاً وسهلاً! أنا بنفوش… شو اسمك يا عالِم؟» — وعيناه تلاحقان الماوس |
| ٢ | اضغط «عرّفني عليك» واكتب اسمك (مثلاً: سارة) | «يا أهلاً يا سارة! اسم بيليق بعالِم حقيقي…» ويتذكر الاسم دائماً |
| ٣ | اسأل: «ليش السفينة الحديد بتطفو؟» | جواب محفوظ فوري ودقيق عن المجوّف والمي المزاحة |
| ٤ | اسأل: «ليش السماء زرقاء؟» | يرسله لـ Grok — الجواب يُكتب أمام الجمهور حرفاً حرفاً |
| ٥ | اضغط «اختبرني» واختر جواباً | سؤال باختيارات؛ الجواب الصح ← «صح يا بطل!» + قصاصات ملوّنة |
| ٦ | اكتب: «افتح تجربة الخلية» | «يلا! بفتحلك رحلة داخل الخلية…» ويفتحها بنفسه |
| ٧ | داخل التجربة انتظر ثانيتين | بنفوش الصغير يطل من الزاوية: «يلا ابدأ! …» مع أول خطوة |
| ٨ | لا تلمس شيئاً ١٥ ثانية | «… عندك أسئلة؟» مع زرّين للمساعدة |
| ٩ | جرّب التجربة ٢٥ ثانية فأكثر ثم ارجع للرئيسية | «يا بطل! خلّصت التجربة لحالك وبدون مساعدة!» + معلومة + احتفال |
| ١٠ | مرّر الماوس على ٣ بطاقات مختلفة بسرعة | «محتار بين الطفو والأس الهيدروجيني؟ لو أنا منك ببلّش بـ…» |
| ١١ | اضغط على بنفوش ٣ مرات بسرعة | «هههه بتزغزغني!» |

> نصيحة: إذا ما بدك تستنى التوقيت الطبيعي في العرض، استعمل مفاتيح العرض بالأسفل.

## مفاتيح العرض (تشغيل أي سيناريو فوراً)

اضغط **Alt + Shift + الرقم**:

**في الشاشة الرئيسية**

| المفتاح | السيناريو |
|---------|-----------|
| 1 | الترحيب وسؤال الاسم |
| 2 | الطالب سرحان (خمول) ← يقترح تجربة |
| 3 | التردد بين البطاقات ← يقترح واحدة مع السبب |
| 4 | التحديق ببطاقة ← يشوّق للتجربة المحددة |
| 5 | حدّد تجربة وما بدأ ← «ابدأ! اضغط الزر الأخضر» |
| 6 | حركة ماوس عصبية ← «على مهلك يا بطل» |
| 7 | «يا بطل! خلّصتها لحالك» + احتفال |
| 8 | «صرت عالِم حقيقي! جرّبت كل التجارب» + احتفال |
| 9 | بنفوش ينعس (عيون نصف مغمضة) — أي حركة توقظه |
| 0 | فتح / إغلاق المحادثة |
| R | مسح ذاكرة بنفوش (الاسم والتجارب) |

**داخل أي تجربة**

| المفتاح | السيناريو |
|---------|-----------|
| 1 | «يلا ابدأ!» + الخطوة الأولى |
| 2 | تلميح + «عندك أسئلة؟» |
| 3 | «شكلك عم تعيد كتير… بدك تلميح؟» |
| 4 | «شغل حلو! كمّل هيك يا بطل» |
| 0 | فتح / إغلاق المحادثة |

## ماذا يراقب بنفوش تلقائياً

- **الخمول**: ١٢ ثانية بلا حركة في الرئيسية ← يقترح، ٣٨ ثانية ← ينعس.
- **التردد**: المرور على ٣ بطاقات مختلفة خلال ٨ ثوانٍ بدون اختيار.
- **التحديق**: إبقاء الماوس فوق بطاقة واحدة ٣ ثوانٍ.
- **التأخر**: تحديد تجربة بدون بدئها لمدة ٩ ثوانٍ ← «ابدأ!».
- **الحركة العصبية**: تحريك الماوس بسرعة يميناً ويساراً.
- **المغادرة**: خروج الماوس من أعلى الصفحة ← «لوين رايح؟».
- **داخل التجربة**: ١٥ ثانية خمول ← «عندك أسئلة؟»، الضغط على «إعادة الضبط» مرتين خلال دقيقة ← يعرض تلميحاً، ٤٠ نقرة ← «شغل حلو!».
- **العودة من تجربة**: بعد ٢٥ ثانية فأكثر و٥ تفاعلات ← «يا بطل!» (ويعرف إذا ساعدته أو خلّصتها لحالك)، وإذا رجعت بسرعة ← يسأل إذا كانت صعبة.

## أسئلة مضمونة الجواب (محفوظة)

- مين انت؟ / كيفك؟ / شو لونك المفضل؟ / عيونك؟ / قديش عمرك؟
- ليش السفينة الحديد بتطفو؟ / ليش السمك ما بيغرق؟ / كيف الغواصة بتغطس؟
- شو يعني حمضي؟ / الحليب حامضي؟
- كيف البالون بيلزق بالحيط؟ / شو هو البرق؟
- أحمر وأخضر شو بيعطوا؟ / كيف بيطلع قوس قزح؟
- شو هي النواة؟ / شو هي الميتوكوندريا؟
- اختبرني / احكيلي نكتة / فاجئني بمعلومة / شو بتقترح عليّ؟ / ساعدني / كيف أبدأ؟
- افتح تجربة الطفو (أو أي تجربة) / ابدأ
- اسمي … / شكراً / بحبك / باي

أي سؤال آخر يذهب لـ Grok (يحتاج إنترنت). بدون إنترنت يرد بنفوش بلطف ويقترح اختباراً أو معلومة أو نكتة.

## صوت بنفوش (Grok)

- بنفوش يحكي بصوت Grok: الجملة تُشكَّل بالحركات تلقائياً قبل النطق، وتُقال بمشاعر حسب مزاجه (ضحكة عند «يا بطل»، همس وتنهيدة وهو نايم، دهشة...).
- كل جملة تُولَّد **مرة واحدة فقط** وتُحفظ؛ تكرارها بعد ذلك مجاني وفوري.
- قبل العرض شغّل مرة واحدة: `npm run banfoush:voices` (≈ ٠٫٣٣$) حتى تكون كل جمله المحفوظة جاهزة بلا انتظار.
- السقف: ١٫٩$ أسبوعياً و٠٫٤$ يومياً (للمحادثة والصوت معاً). إذا انتهى يرجع بنفوش تلقائياً لصوت المتصفح المجاني.
- لتغيير الصوت: أضف في `.env.local` سطر `XAI_TTS_VOICE=leo` (أو ara / eve / rex...) ثم أعد تشغيل `npm run dev`.
- التشكيل المحفوظ في `server/tashkeel.json` — تقدر تصحّح أي حركة يدوياً فيه.
